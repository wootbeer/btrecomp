# Progress / Roadmap

Where the port stands. STATUS.md has the full history of how each piece was
found and fixed.

The goal is the original game, running natively: fixes are limited to what
the PC port needs (timing, rendering and runtime differences from the N64),
and leave the game's own behaviour, look and balance alone.

## Working

- **Boot to the title screen and the 3D attract intro**, tested in the
  development sandbox (Linux, software Vulkan).
- **Recompilation**: all game code is in one section with no overlays. The
  symbol file is generated by control-flow analysis
  (`BattleTanxSyms/README.md`), and N64Recomp recompiles all of it with no
  errors. Every division is guarded against a zero divisor.
- **Launcher** with the ROM picker (accepts `.z64`, `.n64` and `.v64`),
  graphics, controls, sound and mod tabs, from RecompFrontend.
- **Audio**: the game's RSP audio microcode (`aspMain`), recompiled from the
  ROM.
- **Saves**: Controller Pak emulation, stored as standard `.mpk` files.
- **Runtime fixes** carried over from the sequel: yields in the engine's
  busy-wait loops, the per-frame UI pump, crash reports.

## Next

- Play through menus and missions; fix what turns up.
- Port the sequel's game-specific fixes to their counterparts here: frame
  timing (the frame timer is `func_8007AD2C`), widescreen culling and HUD
  anchoring, the screen-edge scissor, the cutscene projection.
- Windows and Linux (Steam Deck) releases; the Linux package is built and
  runs here (software Vulkan), not yet tried on a Deck.

## Where things are

| Path | What |
|---|---|
| `battletanx.us.rev0.toml` | N64Recomp config: stubs, hooks, division guards |
| `BattleTanxSyms/` | Symbol file (function boundaries), generated |
| `aspMain.us.rev0.toml` | RSP audio microcode config |
| `src/main/` | Frontend: window, audio, input, config, crash reporting |
| `src/game/` | Game-specific fixes and runtime compatibility |
| `patches/` | Whole-function replacements compiled for MIPS |
| `syms/` | ROM layout, library names, the function list |
| `tools/` | Symbol and config generators, analysis scripts, packaging |
